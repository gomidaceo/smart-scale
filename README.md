# 내 체중계 (smart-scale)

YUNMAI 계열 블루투스 체중계용 개인 안드로이드 앱.

- 체중계에 올라가면 자동 연결·측정·저장
- BMI, 체지방률, 근육량, 체수분, 기초대사량 (가정용 추정치)
- 기록 목록, 그래프(체중/체지방/근육/BMI), 목표 체중
- CSV 내보내기, 통신 로그, 실제 체중 보정 도구

## 설치
[최신 APK 내려받기](../../releases/download/latest/smart-scale.apk) → 폰에서 열어 설치
(처음 한 번 "출처를 알 수 없는 앱 설치 허용" 필요)

측정 기록은 폰에만 저장되며 외부로 전송되지 않습니다.
